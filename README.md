# 小狗起名器 (Dog Name Generator)

一个简洁温馨的网页小工具，专门通过输入“第一印象”来为小狗寻找合适的名字。

## 项目功能

* 灵感匹配：系统会抓取用户输入的关键词（如：贪吃、黑色、调皮等），智能匹配并生成对应风格的专属名字。
* 随机组合：内置多种日系可爱风格的词汇与词缀，每次交互都能生成不同的名字组合。
* 一键重置：提供 Redo 按钮，方便快速清空当前输入和结果，重新进行下一次灵感捕捉。

## 技术实现

本项目为纯前端项目，极其轻量，无需配置复杂的运行环境：
* HTML5：构建页面的基础骨架与语义化结构。
* CSS3：实现日系蓝黄色调的视觉风格、排版布局以及按钮的悬停交互效果。
* 原生 JavaScript：处理用户输入监听、关键词匹配判断以及最终名字结果的渲染逻辑。
