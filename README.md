# 🐾 汪星人命名所 (Dog Name Generator)

> 一个充满温暖与日系可爱风的网页小工具，专门为你的小狗寻找最契合的名字！✨

## 🌟 项目简介

当一只毛茸茸的小生命来到你的世界，你想好给它起什么名字了吗？
**「汪星人命名所」** 诞生于这样一个温馨的初衷：你只需要输入对小狗的“第一印象”（比如：贪吃、调皮、软萌、黑色），它就会为你捕捉灵感，生成一个充满爱意、独一无二的名字！

页面采用柔和的蓝黄色调，搭配简洁可爱的日系扁平化设计，希望能在这个小小的起名过程中，给你带来治愈的体验。💛💙

## ✨ 核心功能

* 🎨 **极简治愈风**：清爽的天蓝色与淡黄色 UI 设计，搭配可爱的交互动画。
* 🧠 **灵感捕捉**：根据输入的“印象关键词”，智能匹配不同风格（如吃货风、毛色风、性格风）的专属名字。
* 🎲 **随机掉落惊喜**：内置多种日系可爱词缀（如：酱、球、太郎、Yuzu），每次点击都有新发现。
* 🔄 **无缝重置**：一键 "Redo"，清空思绪，直到遇见那个让你心动的名字。

## 🛠️ 技术栈

本项目极其轻量，纯前端实现，无需任何复杂的环境配置：
* **HTML5** (搭建骨架)
* **CSS3** (绘制颜值)
* **Vanilla JavaScript** (注入灵魂)
